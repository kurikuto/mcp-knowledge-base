# MCP

Model Context Protocol (MCP) は、AI アプリケーションがツールやデータへ一貫した形で接続するためのプロトコルです。このリポジトリでは Markdown を正本として、ドキュメントサイトと MCP サーバーの両方へ提供します。

## このサーバーの境界

読み取り対象は `docs/` 配下の `.md` ファイルだけです。パスの正規化とルート検査により、`docs/` 外のファイルは読めません。
